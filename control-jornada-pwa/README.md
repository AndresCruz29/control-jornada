# Control de Jornada PWA

## Instalar y probar
1. Instala Node.js 20 o superior.
2. En esta carpeta ejecuta:
   npm install
   npm run dev
3. Abre la dirección mostrada por Vite.

## Crear versión para publicar
npm run build

La carpeta `dist` será la que debes subir a un hosting HTTPS.

## Datos
Los marcajes se guardan en `localStorage` del navegador/dispositivo.
